# 미리클 오프보딩 4건 데모 핸드오프

## 목적
프디 오프보딩 4건(히스토리, 디어요 캔버스 요청, AI 법 로고 합성, NSFW 4단계 경고)의 통합 데모를 로컬 데모 폴더에 적용함.

## 현재 상태
- 구현 완료 파일: offboarding-demo/index.html, 단일 파일, 외부 의존 없음
- 브랜치: ccr-781552d4-fdhp0s, 드래프트 PR #1
- 검증: Playwright로 4건 주요 시나리오 확인, 콘솔 오류 없음
- 기준 명세: 업로드 zip의 02_데모_제작_명세와_가상_QA_UT.html, 01_핸드오프_본문.html

## 로컬 적용 작업
1. git fetch origin ccr-781552d4-fdhp0s 후 offboarding-demo/index.html을 로컬 데모 폴더로 가져옴
2. 기존 04_디어요_캔버스_요청_데모.html은 팝오버 300px이라 명세 360px과 다름. 대체할지 별도 파일로 둘지 사용자에게 확인
3. 브라우저로 열어 상황 전환 패널 스위치 10개와 추가 5개 동작 확인
4. 실제 Figma 또는 Gitea에서 헤더, 패널, 모달 실제 수치를 찾으면 CONFIG 값에 반영

## 구조
- CONFIG: 파일 상단 한 곳. 헤더 56, 왼쪽 패널 320, 모달 720, 팝오버 360, 1회 차감량 20, 차단 2회와 3회, 제한 1분 등
- 가짜 API: api() 함수. GET /ai-results, GET /ai-results/{id}/download, POST /dieyo/requests, GET /me/restriction
- 상태: S 객체가 상황 스위치와 연결됨. 디어요 결과는 localStorage에 저장

## 미확정, 사용자 확인 필요
- 임시값 전부 CONFIG 참고
- 4단계 아동 관련 문구는 비워 둠, 누리님 정책 대기
- 동영상과 프레젠테이션은 PNG 한 장으로 다운로드됨, 실제 합성 방식은 개발이 결정
- 본문 문구와 데모 문구의 글자 단위 전수 대조는 미수행
- 히스토리 보류 항목(3단 구성, 개별 삭제, 이어서 하기)은 의도적으로 제외
